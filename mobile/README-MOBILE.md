# DM-System Mobile

Мобільний клієнт DM-System на React Native + Expo. Він використовує той самий GraphQL backend та MongoDB, що й вебзастосунок.

## Запуск

1. Відкрий папку `mobile` у WebStorm/VS Code.
2. Створи файл `.env` на основі `.env.example`.
3. Вкажи IPv4 комп'ютера у своїй Wi-Fi мережі:
   `EXPO_PUBLIC_GRAPHQL_URL=http://192.168.0.216:4001/`
   Якщо адреса комп'ютера змінилася, заміни її на актуальну.
4. Переконайся, що GraphQL backend запущений на порту 4001 і комп'ютер/телефон у тій самій Wi-Fi мережі.
5. Виконай:
   `npm install`
   `npx expo install expo-secure-store react-native-safe-area-context`
   `npx expo start -c`
6. Відскануй QR-код у Expo Go.

Якщо телефон не підключається, дозволь Node.js доступ у Windows Firewall для приватної мережі. Для проблем із локальною мережею можна спробувати `npx expo start --tunnel`.

## Що реалізовано

- Вхід, реєстрація компанії та приєднання за кодом запрошення.
- Зберігання JWT у SecureStore.
- Огляд показників каталогу та замовлень.
- Каталог: пошук, фільтрація за категорією, додавання, редагування та видалення товарів (адміністратор).
- Замовлення: пошук, фільтрація за статусом, створення замовлення з кількома позиціями (дропшипер), зміна статусу та видалення (адміністратор).
- Команда: створення запрошень на 7 днів, перегляд учасників, активація/деактивація, відкликання запрошень.
- Налаштування компанії та профіль.
- Рольове відображення розділів і даних.

## Структура

- `App.js` — стан застосунку, GraphQL операції, навігація та логіка.
- `src/api.js` — запити GraphQL та зберігання токена.
- `src/components/Header.js` — заголовок.
- `src/components/ProductForm.js` — форма товару.
- `src/components/ProductItem.js` — картка товару.
- `src/components/OrderItem.js` — картка замовлення.

## Важливо

Мобільний клієнт використовує спільний backend з вебверсією, тому зміни товарів, замовлень, користувачів і компанії синхронізуються між пристроями. Не додавай реальний `.env` або паролі до архіву чи Git.

Перед здачею перевір на телефоні: вхід, реєстрацію/приєднання, додавання/редагування/видалення товару, створення замовлення з кількома товарами, зміну статусу замовлення, керування користувачами та оновлення компанії.
