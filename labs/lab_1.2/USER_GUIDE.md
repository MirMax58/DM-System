# Інструкція користувача DM-System

## 1. Вступ

### 1.1. Сфера застосування системи

DM-System (Dropship Manager System) — навчальна вебсистема, призначена для демонстрації базових можливостей керування товарами та замовленнями в межах моделі дропшипінгу.

Система дає змогу:
- переглядати основні можливості платформи;
- додавати товари до каталогу;
- переглядати назву, ціну та кількість товару;
- створювати замовлення на основі наявних товарів;
- переглядати створені замовлення;
- видаляти товари з каталогу;
- зберігати інформацію про товари та замовлення у локальному сховищі браузера.

Інструкція розрахована на користувачів із базовими навичками роботи з персональним комп'ютером і веббраузером.

Для ознайомлення з проєктом також варто переглянути вихідні файли `index.html`, `style.css` та `script.js`.

## 2. Призначення та умови застосування

### 2.1. Призначення системи

DM-System призначена для демонстрації роботи простого каталогу товарів і механізму створення замовлень.

Система може використовуватися для ознайомлення з принципами роботи вебінтерфейсу, обробки форм, взаємодії JavaScript з HTML-елементами та збереження даних у Local Storage.

### 2.2. Умови застосування

Для роботи із системою необхідні:

- персональний комп'ютер або ноутбук;
- операційна система Windows, Linux або macOS;
- сучасний веббраузер із підтримкою JavaScript та Local Storage;
- наявність файлів `index.html`, `style.css` і `script.js` в одній папці.

Додаткове встановлення програмного забезпечення та зовнішніх бібліотек не потрібне.

Для запуску системи не потрібне постійне підключення до Інтернету, оскільки основні файли застосунку зберігаються локально.

## 3. Підготовка до роботи

### 3.1. Підготовка файлів

Перед запуском необхідно переконатися, що проєкт містить такі файли:

- `index.html` — основна HTML-сторінка;
- `style.css` — файл стилів;
- `script.js` — файл JavaScript, який відповідає за функціональність системи.

Усі три файли повинні знаходитися в одній папці.

### 3.2. Запуск системи

Для запуску необхідно:

1. Відкрити папку проєкту.
2. Знайти файл `index.html`.
3. Двічі натиснути на нього або вибрати команду відкриття у веббраузері.
4. Дочекатися завантаження сторінки.

### 3.3. Ознаки успішного запуску

Якщо система запустилася правильно, у браузері відображається сторінка DM-System із заголовком, навігацією, інформаційним блоком та розділом основних можливостей.

## 4. Опис функціональних можливостей

### 4.1. Головна сторінка

Після запуску користувач бачить назву DM-System, навігаційні посилання та інформаційний блок із коротким описом призначення системи.

Кнопка «Переглянути можливості» прокручує сторінку до відповідного розділу.

Навігаційні посилання дають змогу перейти до розділів сторінки: «Можливості», «Товари» та «Замовлення».

*Рисунок 1 – Головна сторінка DM-System.*

### 4.2. Перегляд основних можливостей

У розділі «Основні можливості» відображається перелік функцій системи: перегляд каталогу товарів, створення замовлень, перегляд замовлень та керування товарами.

*Рисунок 2 – Розділ основних можливостей.*

### 4.3. Додавання товару

У розділі «Каталог товарів» розташована форма для додавання нового товару.

Користувач повинен заповнити такі поля:
- назва товару;
- ціна;
- кількість.

Після введення даних необхідно натиснути кнопку «Додати товар».

Якщо дані відповідають встановленим обмеженням, товар додається до каталогу та відображається на сторінці.

*Рисунок 3 – Форма додавання товару та каталог.*

### 4.4. Перегляд каталогу товарів

Після додавання товару він відображається у вигляді картки. У картці показуються назва, ціна та кількість товару.

Для кожного товару доступні кнопки «Замовити» та «Видалити».

*Рисунок 4 – Товар у каталозі.*

### 4.5. Створення замовлення

Для створення замовлення користувач натискає кнопку «Замовити» у картці відповідного товару.

Після натискання система:
1. Перевіряє наявність товару.
2. Зменшує його кількість на одну одиницю.
3. Створює нове замовлення.
4. Зберігає інформацію про замовлення.
5. Оновлює відображення каталогу та списку замовлень.

У замовленні відображаються назва товару, сума, статус і дата створення.

*Рисунок 5 – Створене замовлення.*

### 4.6. Видалення товару

Для видалення товару необхідно натиснути кнопку «Видалити» у відповідній картці.

Після виконання операції товар видаляється з каталогу, а список товарів оновлюється.

*Рисунок 6 – Видалення товару з каталогу.*

### 4.7. Збереження даних

Інформація про товари та замовлення зберігається у Local Storage браузера.

Завдяки цьому дані можуть залишатися доступними після перезавантаження сторінки в тому самому браузері.

*Рисунок 7 – Дані DM-System у Local Storage браузера.*

## 5. Аварійні ситуації

### 5.1. Помилкове введення даних

Якщо користувач не заповнив обов'язкове поле або ввів некоректне значення ціни чи кількості, браузер або система повідомляє про необхідність перевірити введені дані.

Потрібно виправити значення та повторити додавання товару.

Ціна повинна бути більшою за нуль, а кількість — додатним цілим числом.

### 5.2. Відсутність товарів у каталозі

Якщо каталог порожній, система відображає повідомлення «Каталог поки порожній».

Для продовження роботи необхідно додати новий товар через форму.

### 5.3. Відсутність товару на складі

Якщо кількість товару дорівнює нулю, створити замовлення для нього неможливо. Система відображає відповідне повідомлення.

### 5.4. Проблеми зі збереженням даних

Якщо браузер не підтримує Local Storage або доступ до нього обмежений, збереження даних може працювати некоректно.

Рекомендується використовувати сучасний браузер і не очищати дані сайту, якщо потрібно зберегти каталог та замовлення.

### 5.5. Відсутність підключення до Інтернету

Основні функції початкової версії системи не потребують постійного підключення до Інтернету, оскільки HTML, CSS і JavaScript завантажуються з локальних файлів.
