# Матеріали лабораторної роботи №3 — DM-System

Зображення взято з рисунків у правильному звіті `lab_3(6).docx` з дисципліни «Технології створення програмних продуктів». Назви файлів зроблено зрозумілими для зберігання в репозиторії.

### Архітектурна діаграма (`architecture.png`)

Трирівнева клієнт-серверна архітектура DM-System: вебінтерфейс, серверна бізнес-логіка та база даних.

### ER-діаграма (`er-diagram.png`)

Структура даних DM-System із сутностями Company, User, Invitation, Product, Order та OrderItem і зв’язками між ними.

### Wireframe (`wireframe.png`)

Схематичний макет шести екранів: вхід, вибір способу реєстрації, створення компанії, приєднання до компанії, каталог дропшипера та панель адміністратора.

### Mockup (`mockup.png`)

Статичний візуальний макет ключових екранів DM-System, який відповідає рисунку 4 у звіті.
